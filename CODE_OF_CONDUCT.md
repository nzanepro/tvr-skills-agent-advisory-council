# Code of conduct

This is a small open-source project maintained in spare time. Everyone who takes part in its
issues, pull requests and reviews is asked to keep it a place where people can disagree about
the work without it becoming about each other. The spirit is the same as the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/); this
page says how it applies here.

## Expected

- Be kind and assume good intent. Many contributors write in a second language.
- Argue about the work, not the person. A council that keeps the dissent is the point of this
  project; the same goes for its issue threads.
- Accept a decision you disagree with once it is made, and say so if new evidence turns up.
- Credit other people's ideas and code.

## Not acceptable

- Harassment, insults, slurs, or personal or political attacks.
- Sexualised language or imagery, and unwelcome attention of any kind.
- Publishing someone's private information (addresses, emails, real names behind an account)
  without their permission.
- Sustained disruption of discussions, or deliberately derailing an issue.
- Anything else a reasonable person would consider inappropriate in a professional setting.

## Reporting

If someone's behaviour here bothers you, use GitHub's **Report content** option in the "..."
menu of the comment, issue or pull request, and choose to report it to the repository's
maintainers where GitHub offers that. If that is not available, open an issue that says only
that you have a conduct report and asks for a private way to reach the maintainer; do not put
the details in the public issue.

Reports are read by the maintainer, kept confidential, and answered as soon as practical.

## What happens

The maintainer may edit or remove comments, commits, issues and pull requests that break this
code, and may warn, temporarily block or permanently ban a contributor, depending on how serious
and how repeated the behaviour is. Decisions are explained to the people involved where that is
safe to do.

## Scope

This code applies in this repository's issues, pull requests, reviews and any other space where
someone represents the project.
